## Опис

Адаптивний багатосторінковий навчальний вебсайт спортзалу «Ритм», створений у межах комп’ютерного практикуму №1 з дисципліни «Технології розробки WEB-орієнтованих систем». HTML5 та CSS3; серверна частина, база даних та справжній запис відсутні за умовами етапу №1.

## Сторінки

| Файл | Призначення |
| --- | --- |
| `index.html` | Головна сторінка |
| `trainings.html` | Каталог шести видів тренувань |
| `strength-training.html` | Опис одного тренування |
| `about-gym.html` | Інформація про спортзал |
| `training-signup.html` | Демонстраційна форма запису з валідацією HTML5 |

Інші файли: `styles/main.css` — стилі, `assets/` — оптимізовані зображення та логотип, `lab-report/` — звіт (LaTeX і PDF), схема сайту та скриншоти.

## Запуск

Відкрийте `index.html` у браузері або запустіть локальний сервер:

```bash
python -m http.server 8000
```

Тоді відкрийте `http://localhost:8000`. Усі необхідні зображення зберігаються локально. JavaScript-фреймворки не потрібні.

## Технічні рішення

- Семантична HTML5-структура: `header`, `nav`, `main`, `section`, `article`, `footer`.
- CSS Grid та Flexbox; медіазапити на 900 та 600 пікселях.
- Альтернативні тексти зображень, підписи полів форми, навігація з клавіатури.
- Форма демонструє `required`, `type=email`, `pattern`, `minlength`, `maxlength` та CSS `:target`.
- **Дані форми не зберігаються й не відправляються до адміністратора.**
